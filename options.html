Template Generator

Create configs. The default one is preselected in the popup and used by the shortcut. Changes save automatically.

Keyboard shortcuts

Alt+Shift+C copies the default config. Configs #1, #2 and #3 (their order above) can each get their own key. A green check appears on the toolbar icon when text is copied.

Placeholders

Use these inside a template. Unknown placeholders are left as typed.

{{number/8}}random 8-digit number
{{number/1-100}}number in a range
{{digits/6}}digits, may start with 0
{{alpha/6}}{{lower/6}}{{upper/6}}random letters
{{alnum/10}}{{hex/8}}letters and digits, or hex
{{uuid}}UUID v4
{{date}}{{date/DD-MM-YYYY}}today, with optional format (YYYY YY MM DD HH mm ss)
{{time}}{{datetime}}{{timestamp}}current time, date and time, or Unix ms
{{name}}{{email}}{{phone}}fake test data
{{pick/open,closed,blocked}}random item from a list
{{seq}}{{seq/100}}counter across lines (1, 2, 3… or from 100)
{{lorem/5}}5 lorem ipsum words
